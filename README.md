
# Cloud Computing - Tutorial 1

Google Colab project for Cloud Computing.

## Project Description
Student information management using Python and ipywidgets.

## Features
- Load student information from Google Drive
- Select a student from a dropdown list
- Display student details
- Update a student's favorite TV show
- Append updated information to students.txt

## Technologies
- Python
- Google Colab
- Google Drive
- ipywidgets
